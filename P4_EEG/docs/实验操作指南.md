# P4 EEG 实验操作指南

> [!important]
> 本指南用于每天从开机到运行 P4 EEG 实验脚本。核心原则：先无硬件测试，再接真实 EEG；先确认环境和 Trigger，再采正式数据；任何时候不要手动删除、移动或提交 `data/` 目录下的真实数据。

相关文档：[[proposal|P4 proposal]]、[[paper_blueprint|Paper 1 Blueprint]]、[[experiment/README|实验代码说明]]。

也可以用：


但 PsychoPy GUI 程序更推荐先 `conda activate eeg-p4`，再直接 `python launcher.py ...`。

## 3. 无硬件测试流程

无硬件测试用于确认 PsychoPy 窗口、中文显示、键盘、流程和数据保存，不连接 EEG 设备，也不发送真实 Trigger。

进入实验目录：

```bat
D:
cd D:\EEG_Project\P4_EEG\experiment
conda activate eeg-p4
```

### 3.1 Session 1：静息态测试

```bat
python launcher.py --subject Test_01 --session 1 --windowed --no-hardware
```

检查：

- [ ] 能打开窗口
- [ ] 中文指导语正常
- [ ] 空格键能继续
- [ ] 十字能显示
- [ ] ESC 能安全退出
- [ ] 结束后能保存测试 `.npz`

### 3.2 Session 2：伪迹模板测试

```bat
python launcher.py --subject Test_01 --session 2 --windowed --no-hardware
```

检查：

- [ ] 能播放滴声
- [ ] 单眨眼、连眨、扫视、咬牙、吞咽流程正常
- [ ] 每类试次能推进
- [ ] 结束后能保存测试 `.npz`

### 3.3 Session 3：银标准任务态测试

```bat
python launcher.py --subject Test_01 --session 3 --windowed --no-hardware
```

Session 3 包含：

- Oddball：200 trials
- 任务间重基线：1 分钟
- SSVEP：80 trials（4 个频率 × 20 次）

检查：

- [ ] Oddball 蓝/红圆显示正常
- [ ] 每 100 trials 行为验证弹窗正常
- [ ] SSVEP 方块闪烁正常
- [ ] SSVEP 实际帧率接近 60Hz
- [ ] 结束后保存 oddball 和 ssvep 两个文件

### 3.4 Session 4：自然污染测试集测试

```bat
python launcher.py --subject Test_01 --session 4 --windowed --no-hardware
```

检查：

- [ ] 自然态指导语正确
- [ ] Oddball Marker 逻辑为 81 (标准) / 82 (靶)
- [ ] SSVEP Marker 逻辑为 91 / 92 / 93 / 94 (6 / 8.57 / 10 / 15 Hz)
- [ ] 强制眨眼提示能出现
- [ ] S4 全部 Marker 均 < 128, 不再使用早期 "+1000" 方案

### 3.5 全流程测试

代码已支持：

```bat
python launcher.py --subject Test_01 --session all --windowed --no-hardware
```

> [!tip]
> 第一次建议还是分 Session 跑，方便定位问题。等 S1-S4 单独都确认过，再跑 `--session all`。

## 5. 正式实验当天流程

### 5.1 开机与设备准备

1. 打开 EEG 采集电脑和刺激电脑。
2. 打开 EEG 采集软件。
3. 确认 EEG 波形正常。
4. 确认阻抗达标：所有通道 < 10 kΩ，最好 < 5 kΩ。
5. 重点关注：Fp1/Fp2、Oz/O1/O2、Pz。
6. 确认数据保存路径。
7. 确认 Trigger 端口号。

> [!warning]
> 正式采集时不要用真实姓名作为 subject id。统一使用 `Sub_001` 这类匿名编号。

### 5.2 打开实验终端

```bat
D:
cd D:\EEG_Project\P4_EEG\experiment
conda activate eeg-p4
python --version
```

确认 Python 是 3.10.20。

### 5.3 Session 1：静息态

如果真实端口是 COM3：

```bat
python launcher.py --subject Sub_001 --session 1 --port COM3
```

如果端口是 COM4：

```bat
python launcher.py --subject Sub_001 --session 1 --port COM4
```

主试注意：

- [ ] 睁眼阶段盯住十字
- [ ] 尽量少眨眼、少吞咽
- [ ] 闭眼阶段保持清醒
- [ ] 如果被试快睡着，及时提醒

### 5.4 Session 2：伪迹模板

```bat
python launcher.py --subject Sub_001 --session 2 --port COM3
```

主试注意：

- [ ] 按空格后先静止 2 秒
- [ ] 听到滴声才做动作
- [ ] 扫视只动眼球，不动头
- [ ] 咬牙不要过度用力
- [ ] 记录明显错误 trial

### 5.5 休息与阻抗复查

- [ ] 休息 5 分钟
- [ ] 检查阻抗
- [ ] 检查 EEG 波形是否漂移
- [ ] 被试喝水、调整坐姿

### 5.6 Session 3：银标准任务态

```bat
python launcher.py --subject Sub_001 --session 3 --port COM3
```

主试必须反复强调：

> [!danger]
> Session 3 是最重要的干净 Ground Truth。刺激出现期间绝对不能眨眼、不能咬牙、不能吞咽、不能动头。只能在黑屏或休息提示时眨眼。

检查：

- [ ] Oddball 阶段被试默数红圆
- [ ] 每 100 trials 口头确认红圆数量
- [ ] SSVEP 闪烁期间被试盯住目标方块
- [ ] 记录任何刺激期眨眼或明显动作

### 5.7 长休息

- [ ] 休息 10 分钟
- [ ] 被试活动、喝水
- [ ] 主试检查设备连接和阻抗

### 5.8 Session 4：自然污染测试集

```bat
python launcher.py --subject Sub_001 --session 4 --port COM3
```

指导语重点：

> [!note]
> Session 4 是自然污染测试集。被试可以自然眨眼，不需要刻意控制面部动作，但仍要完成同样任务。

检查：

- [ ] Oddball 自然态任务正常
- [ ] SSVEP 自然态任务正常
- [ ] Marker 为 S4 的独立 8-bit 编码（不再使用 S3 Marker + 1000）
- [ ] 记录异常情况

## 6. 数据保存与保护

默认保存目录：

```text
D:\EEG_Project\P4_EEG\experiment\data
├── eeg-bdf\              # iRecorder 保存的 EEG 原始 .bdf
├── eeg-npz\              # PsychoPy 每个 Session 的 .npz 元数据
└── video_records\        # FFmpeg 相机录制
```

PsychoPy NPZ 典型输出 (`experiment/data/eeg-npz/`)：

```text
P4_S1_Sub_001_时间_session1.npz
P4_S2_Sub_001_时间_session2.npz
P4_S3_Sub_001_时间_session3_oddball.npz
P4_S3_Sub_001_时间_session3_ssvep.npz
P4_S4_Sub_001_时间_session4_mi.npz
```

> [!danger]
> `data/` 目录禁止加入 git，禁止随意删除、移动、重命名。真实被试数据只能按实验室规定备份，不能让 Claude 自动处理。

## 7. 常见问题处理

### 7.1 Python 版本不对

现象：

```text
Python 3.13.x
```

处理：

```bat
conda activate eeg-p4
python --version
```

### 7.2 PsychoPy 窗口打不开

检查：

- 是否在 `eeg-p4` 环境
- 是否先试 `--windowed`
- 是否有其他全屏软件占用显示器

测试命令：

```bat
python launcher.py --subject Test_01 --session 1 --windowed --no-hardware
```

### 7.3 串口连接失败

处理：

1. 打开设备管理器。
2. 查看“端口 COM 和 LPT”。
3. 把命令里的 `--port COM3` 改成真实端口。

例如：

```bat
python launcher.py --subject Sub_001 --session 1 --port COM4
```

### 7.4 无硬件模式

没有 EEG 设备时使用：

```bat
python launcher.py --subject Test_01 --session 1 --windowed --no-hardware
```

### 7.5 SSVEP 帧率不对

检查 Windows 设置：

```text
设置 → 系统 → 屏幕 → 高级显示器设置 → 刷新率
```

建议固定为 60Hz。
