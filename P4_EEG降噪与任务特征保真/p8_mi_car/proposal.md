# P8: MI 脑控模拟小车 — 基于运动想象的实时 BCI 虚拟车辆控制

## 核心问题

> 能否构建一个**纯电脑端**的 MI-BCI 模拟小车系统，让用户通过运动想象（想象左手/右手/脚/舌）实时控制虚拟小车在 2D 赛道上行驶？整个 pipeline 从 EEG 采集/模拟 → 实时预处理 → MI 分类 → 模拟小车控制，全部在 Python 环境中完成，无需实物硬件。

---

## 1. 研究背景与动机

### 1.1 为什么做这个项目

- **验证 MI 实时解码的可行性**：离线准确率 ≠ 在线准确率（Audrey-Li 项目：98% → 26%），需要一个端到端的实时系统来暴露真实瓶颈
- **填补空白**：现有开源项目几乎全部接实物小车（Arduino + 电机），**没有一个纯电脑端模拟方案**
- **为 P5 在线自适应系统提供验证平台**：P5 的 Foundation Model + 快慢双系统自适应架构可以在 MI 控制任务上验证
- **低门槛可复现**：不需要 EEG 设备即可用公开数据集 + 键盘模拟跑通整个系统

### 1.2 现有项目调研

详见 [[competitive_landscape|竞品与现有项目调研]]。

**关键发现**：
- GitHub 上找到 ~10 个脑控小车项目，全部是物理硬件方案
- 最接近的参考：[Audrey-Li/EEG-Brainwave-Controlled-RaceCar](https://github.com/Audrey-Li-CPEN/EEG-Brainwave-Controlled-RaceCar)（14ch Emotiv EPOC+，4 类 MI，F1TENTH 物理赛车）
- PubMed 找到 9 篇脑控车辆论文，核心研究组 Bi L.（5 篇），聚焦横向+纵向联合控制
- **没有找到任何纯 Python 端到端模拟方案**

## 2. 系统架构

### 2.1 整体 Pipeline

```
┌─────────────────────────────────────────────────────────────────────┐
│                     纯电脑端模拟架构                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌──────────┐    ┌──────────────┐    ┌──────────────┐    ┌────────┐ │
│  │ EEG 数据  │ →  │  实时预处理   │ →  │  MI 分类器    │ →  │ 指令    │ │
│  │ 采集/模拟  │    │  (MNE-Python)│    │  (CSP+LDA)   │    │ 映射    │ │
│  └──────────┘    └──────────────┘    └──────────────┘    └───┬────┘ │
│                                                              │      │
│  ┌──────────────────────────────────────────────────────────┐│      │
│  │              模拟小车环境（Pygame）                        ││      │
│  │  2D 俯视赛道 + 小车 sprite + 障碍物 + 计时/得分           │←──────┘
│  └──────────────────────────────────────────────────────────┘        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 模块详细设计

#### Module A: EEG 数据源（双模式）

| 模式 | 说明 | 适用场景 |
|:---|:---|:---|
| **Mode 1: 键盘模拟** | 键盘按键（↑↓←→）直接映射为分类结果 | 无设备时验证游戏逻辑 |
| **Mode 2: 数据集回放** | 回放 BCI Competition IV-2a 的 .gdf 文件，模拟实时流 | 验证分类器端到端性能 |
| **Mode 3: 实时 EEG** | BrainFlow/Muse LSL 采集真实脑电 | 有设备时的完整 BCI 体验 |

#### Module B: 实时预处理

```python
# 基于 MNE-Python 的实时预处理 pipeline
1. 带通滤波：8-30 Hz（μ + β 节律）
2. 陷波滤波：50 Hz（工频干扰）
3. CAR（公共平均参考）
4. 滑动窗口：2 秒窗口，0.5 秒步长（4 Hz 更新率）
```

#### Module C: MI 分类器

**Phase 1 — 经典方法（先跑通）**：
- CSP (Common Spatial Pattern) + LDA
- 训练数据：BCI Competition IV-2a（9 通道，22 通道，4 类 MI）

**Phase 2 — 深度学习（进阶）**：
- EEGNet（端到端 CNN baseline）
- 可选：EEG-MFTNet、Spatial-Temporal Mamba 等 2024-2026 架构

**Phase 3 — 在线自适应（与 P5 联动）**：
- Foundation Model 冻结 + Adapter 慢速适配 + fast_context 快速调整
- 参考 P5 proposal 中的双速协同架构

#### Module D: 指令映射

> [!note] 实验四的推荐收敛方式
> 当前建议把“实验四”拆成 `4A → 4B → 4C` 的顺序路线，而不是在“双手 MI”和“在线小车”之间二选一。
> - **实验 4A**：双手 MI 采集 + 离线分类
> - **实验 4B**：双手 MI 驱动二维平面小车（先伪在线，再真在线）
> - **实验 4C（可选）**：扩展到 4 类 MI（脚/舌加入速度或停止控制）

**实验 4A / 4B 优先方案：2 类 MI**（左手/右手）
| MI 类别 | 小车指令 | 说明 |
|:---|:---|:---|
| 左手 | 左转 | 第一版只负责转向 |
| 右手 | 右转 | 小车保持固定前进速度 |

**实验 4C 扩展方案：4 类 MI**（左手/右手/脚/舌）
| MI 类别 | 小车指令 | 说明 |
|:---|:---|:---|
| 左手 | 左转 | 扩展到更完整控制 |
| 右手 | 右转 | 扩展到更完整控制 |
| 脚 | 加速/前进 | 仅在 2 类稳定后再引入 |
| 舌 | 刹车/停止 | 仅在 2 类稳定后再引入 |

#### Module E: 模拟小车环境

- **引擎**：Pygame
- **视角**：2D 俯视
- **赛道**：简单环形 → 复杂弯道 → 障碍物避让
- **物理模型**：简化的差速转向（左转/右转改变航向角，前进按当前航向移动）
- **反馈**：实时显示小车位置、方向、速度、当前 MI 分类结果、置信度
- **记录**：轨迹日志、分类准确率、控制延迟

## 3. 实验设计

> [!important] 实验四的定义
> P8 当前更适合把“实验四”定义为一个分阶段的 MI 路线，而不是单一脚本：
> - **实验 4A**：双手运动想象采集 + 离线分类
> - **实验 4B**：双手 MI 驱动二维平面小车
> - **实验 4C（可选）**：扩展到 4 类 MI 与在线自适应
>
> 这样安排的原因是：当前仓库还没有实现代码，直接进入 4 类真在线控制会把分类、实时推理、控制抖动和环境联调的风险叠加在一起。

### 实验 4A：双手 MI 采集 + 离线分类（第 1 周主线）

**目标**：先验证左手 / 右手两类 MI 是否能稳定分开。

- 优先使用 2 类 MI，不一开始就上 4 类
- 数据源可先用 BCI Competition IV-2a，后续再接真实采集
- 方法：CSP + LDA（baseline）→ EEGNet（进阶）
- 评估：LOSO（Leave-One-Subject-Out）交叉验证 + balanced accuracy + 混淆矩阵
- 输出：训练好的模型文件 + 2 类离线准确率报告

### 实验 4B：双手 MI 驱动二维平面小车（第 2 周主线）

**目标**：把实验 4A 的输出接到二维平面控制任务上。

- 第一版采用 **固定前进速度 + 左右手控制转向**
- 先做数据回放模式：回放 `.gdf` 文件 → 滑窗实时分类 → 控制小车
- 再决定是否进入真实在线 EEG
- 记录：完成赛道时间、碰撞次数、平均延迟、控制平滑性
- 对比：键盘控制 vs 双手 MI 控制的赛道表现差异
- 输出：端到端 demo + 性能对比报告

### 实验 4C（可选）：扩展到 4 类 MI 与在线自适应

**目标**：在 2 类在线 steering 稳定后，再考虑加入脚 / 舌两类与在线自适应。

- 4 类映射：左 / 右 / 加速 / 停止
- 对比：无自适应 vs 慢速自适应 vs 快慢协同
- 指标：分类准确率随时间的变化曲线 + 赛道控制稳定性
- 输出：4 类扩展报告 + 自适应效果对比报告

### 保留的底层阶段（实现视角）

#### Phase 0: 模拟小车 + 键盘控制（1-2 天）

**目标**：验证游戏逻辑和渲染
- Pygame 2D 俯视赛道，键盘控制左 / 右 / 前 / 停
- 赛道渲染、碰撞检测、计时系统
- 输出：可运行的游戏 demo

#### Phase 1: 离线 MI 分类器（2-3 天）

**目标**：支撑实验 4A 的离线分类基线
- 数据集：BCI Competition IV-2a
- 方法：CSP + LDA（baseline）→ EEGNet（进阶）
- 评估：LOSO（Leave-One-Subject-Out）交叉验证
- 输出：训练好的模型文件 + 离线准确率报告

#### Phase 2: 端到端集成（2-3 天）

**目标**：支撑实验 4B 的回放在线化
- 数据集回放模式：回放 `.gdf` 文件 → 实时分类 → 控制小车
- 记录端到端准确率、控制延迟、完成赛道时间
- 对比：键盘控制 vs MI 控制的赛道表现差异
- 输出：端到端 demo + 性能对比报告

#### Phase 3（可选）: 在线自适应验证

**目标**：支撑实验 4C 的扩展验证
- 冻结 Foundation Model → 在线 Adapter 适配
- 对比：无自适应 vs 慢速自适应 vs 快慢协同
- 指标：分类准确率随时间的变化曲线
- 输出：自适应效果对比报告

## 4. 技术栈

| 组件 | 技术选型 |
|:---|:---|
| EEG 采集 | BrainFlow（支持 40+ 种设备） |
| EEG 预处理 | MNE-Python |
| MI 分类器 | scikit-learn (CSP+LDA) / PyTorch (EEGNet) |
| 模拟环境 | Pygame |
| 数据集 | BCI Competition IV-2a（PhysioNet） |
| 可视化 | Matplotlib（静态）/ Pygame（实时） |
| 通信（未来） | LSL (Lab Streaming Layer) |
