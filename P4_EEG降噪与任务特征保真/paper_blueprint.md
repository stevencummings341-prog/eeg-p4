# Paper 1 Blueprint: 面向任务特征保真的 EEG 源分离与数据净化框架

## 论文定位 (Positioning)

这篇论文是整套研究议程的**地基**。它回答的问题是：

> 在把数据喂进 Foundation Model 之前，你怎么知道模型在学脑信号，还是在学咀嚼肌的 EMG？

没有这篇论文的产出（净化后的数据 + 冻结的源分离模型），后续的 Foundation Model 预训练（Paper 2）和在线自适应（Paper 3）都建立在不可靠的数据上。这不是"一个降噪论文"——它是整个研究栈的**质量基础设施**。

**目标期刊**：NeuroImage / Journal of Neural Engineering / Scientific Data（数据集论文路线）

---

## 1. 论文的核心叙事弧 (Narrative Arc)

### 1.1 Introduction 逻辑链

```
段落1: EEG深度学习在临床和BCI中的巨大潜力
  ↓
段落2: 但有一个被系统性忽视的问题 — 数据质量
        - 耳周EEG中脑信号仅占20-40%的能量
        - 深度学习模型可能在学EMG模式而非神经信号
        - 跨被试性能降幅(-29%)中，数据质量差异贡献了多少？
  ↓
段落3: 现有降噪方法（ICA、回归、带通滤波）的三个根本缺陷
        - 线性假设（真实容积传导是非线性的）
        - 任务盲目（优化独立性 ≠ 保留任务特征）
        - 离线批处理（无法流式部署）
  ↓
段落4: 更深层的问题 — 现有数据集的设计缺陷
        - 没有"干净Ground Truth"可供对比
        - 伪迹和任务信号在采集时就已混合，无法事后分离
        - 你无法在一个设计有缺陷的数据集上训出好模型
  ↓
段落5: 本文的贡献
        1. 一套4-Session采集SOP，从源头上分离"信号"和"噪声"
        2. 一个多模态弱监督的源分离预训练框架（非线性ICA替代）
        3. 一个任务感知的复合损失函数（时域+频域+任务驱动联合优化）
        4. 证明：数据质量是下游模型泛化能力的瓶颈 —
           净化后的数据训出的模型，跨被试降幅从-29%压缩到-X%
```

### 1.2 论文的核心张力

**不是**"我们提出了一个新的降噪网络架构"（这是 incremental contribution）。

**而是**"我们重新定义了 EEG 深度学习的起点——不应该是原始信号直接进模型，而应该先经过一个'知道什么是信号、什么是噪声'的净化管道。这个管道不是后处理，不是预处理，而是和数据采集、模型训练联合设计的质量基础设施。"

## 2. Methods 部分映射

### 2.1 数据采集协议

**来源**：[[proposal|P4 proposal]] 的完整 4-Session SOP

```
Session 1 → 纯净静息态基线 (6 min)
  - 睁眼: Marker 11-12
  - 闭眼: Marker 21-22
  - 论文中的角色: "Ground Truth Zero" — 不含任何任务信号的纯脑电底色

Session 2 → 独立伪迹模板 (10 min)
  - 5类伪迹各30-40次: 眨眼/连眨/扫视/咬牙/吞咽
  - Marker 30-45, 关键设计: 按键→静息2s→伪迹执行
  - 论文中的角色: "已知噪声源" — 每种伪迹有明确的物理来源和时间标记

Session 3 → "银标准"高纯净任务态 (20 min)
  - Oddball (P300): Marker 61 (标准) / 62 (靶)
  - SSVEP (频谱尖峰): Marker 71 / 72 / 73 / 74 (6 / 8.57 / 10 / 15 Hz)
  - 任务间重基线: Marker 63
  - 论文中的角色: "Signal Ground Truth" — 保留完美任务特征的干净信号
  - 说明: 当前 P4 范式不包含 MI 运动执行任务; ERD 相关实验留给后续 paper

Session 4 → 自然污染测试集 (20 min)
  - 重复Session 3，但不控制眨眼/面部
  - Oddball: Marker 81 (标准) / 82 (靶)
  - SSVEP: Marker 91 / 92 / 93 / 94
  - Marker 全部 8-bit (< 128), 与单字节 Trigger 协议兼容; 不再使用早期 "+1000" 方案
  - 论文中的角色: "Real-world Test Set" — 唯一的测试基准
```

**论文中的关键卖点**：Session 2 和 Session 3 的物理分离意味着**我们知道每一段数据的信号-噪声成分**。这在现有 EEG 数据集中几乎不存在。

### 2.2 源分离预训练框架

**来源**：[[../../03_Knowledge_Base/EEG数据净化与完整系统工作流|EEG数据净化与完整系统工作流]] Stage 1

```
架构:
  X_raw → Φ_spatial (解混网络, 非线性) → Ŝ_1, ..., Ŝ_K
                                              │
                              ┌───────────────┼───────────────┐
                              ▼               ▼               ▼
                          源分类器         选择性重建       任务编码器
                    标注每个Ŝ的来源    X_clean = Σ皮层源   → 下游任务

损失函数:
  L_purify = L_recon + λ₁ L_indep + λ₂ L_aux + λ₃ L_sparse

  L_recon:   ‖X_raw - Σ Ŝ_k‖²₂ + ‖STFT(X_raw) - STFT(Σ Ŝ_k)‖₁
  L_indep:   Σ|corr(Ŝ_i, Ŝ_j)| + KL(p_joint ‖ Πp_marginal)
  L_aux:     Σ‖Ŝ_k - f_k(Aux_k)‖²  ← 多模态弱监督 (EMG, IMU, Eye)
  L_sparse:  Σ‖Ŝ_k‖₁
```

**与 ICA 的本质区别（论文中的对比表格）**：

| 维度 | ICA | 本文 Φ_spatial |
|:---|:---|:---|
| 混合假设 | 线性 (X = AS) | 非线性 (可学习) |
| 优化目标 | 仅统计独立性 | 独立性 + 物理含义 + 任务相关性 |
| 伪迹标定 | 人工目视检查 | 多模态传感器弱监督 |
| 流式推理 | 不支持 | 支持 (Φ_spatial 冻结后递推) |
| 与下游任务关系 | 解耦 (可能丢失有用信息) | 联合优化 (保留任务相关成分) |

### 2.3 任务感知数据对构建

**来源**：[[../../03_Knowledge_Base/EEG降噪中任务特征保真的深度学习策略|降噪保真策略]]

```
策略A (40%): 基础降噪对
  Y_label = Session 1 纯净静息态片段
  X_input = Y_label + λ · Session 2 随机伪迹模板
  λ ∈ [-7dB, +5dB]
  教会: 什么是"干净脑电"，什么是"伪迹"

策略B (60%): 任务感知对
  Y_label = Session 3 高纯净任务态trial (含P300波峰/ERD能量下降)
  X_input = Y_label + λ · Session 2 随机伪迹模板
  教会: P300的大波峰是信号，不是噪声 — 必须原封不动输出
```

**为什么策略B是核心突破**：

标准降噪训练只用策略A（静息态+噪声）。这意味着模型从未见过任务相关特征（P300、ERD、SSVEP尖峰），所以它不知道这些是"要保留的信号"还是"要消除的噪声"。策略B在训练阶段直接告诉模型：**"这些波形特征属于Y_label，不准动。"**

### 2.4 复合损失函数

**来源**：[[../../03_Knowledge_Base/EEG降噪中任务特征保真的深度学习策略|降噪保真策略]] 第二阶段

$$L_{\text{Total}} = \alpha L_{\text{time}} + \beta L_{\text{freq}} + \gamma L_{\text{task}}$$

**时域损失 $L_{\text{time}}$**：
- 波峰锁定 MSE：P300 窗口（250-450ms）加权
- Pearson 相关损失：$L_{\text{pearson}} = 1 - \text{corr}(y, \hat{y})$，对潜伏期漂移敏感
- ITPC 损失：约束跨 trial 的锁相一致性

**频域损失 $L_{\text{freq}}$**：
- PSD 损失：全频段功率谱密度一致性
- 频带专注损失：$\sum_{b \in \{\mu, \beta\}} \|\text{BP}_b(y) - \text{BP}_b(\hat{y})\|^2$

**任务驱动损失 $L_{\text{task}}$**（联合训练）：
- 冻结的 Classifier（在 Session 3 干净数据上预训练）
- 降噪后的 $\hat{Y}$ → Classifier → CE Loss 回传至降噪器
- 如果降噪器洗掉了 P300，Classifier 会报错 → 梯度迫使降噪器保真

### 2.5 模型架构

```
Denoiser 架构: U-Net style with Mamba2 backbone
  Encoder: SAIE → Conv Stem → Mamba2 (3 stages)
  Bottleneck: MDM (差分Mamba, 双路噪声抑制)
  Decoder: Mamba2 (3 stages, 对称上采样 + skip connections)

Task Classifier (冻结):
  - ERP: EEGNet-style temporal conv + spatial conv
  - MI: FBCSP + shallow ConvNet
  - SSVEP: 频域投影 + 峰值检测

在线部署时的角色:
  训练后, Denoiser = Φ_spatial → 流式净化模块
  Classifier 不部署 (仅在训练时提供任务驱动梯度)
```

### 3.1 核心实验矩阵

| 实验                  | 测试数据                        | 评估指标                       | Baseline                                   | 要证明什么                                      |
| :------------------ | :-------------------------- | :------------------------- | :----------------------------------------- | :----------------------------------------- |
| **Exp 1: 降噪质量**     | Session 4 (自然污染)            | RRMSE (时域+频域)              | ICA, ASR, 1D CNN Denoiser                  | 本文方法在重建精度上全面优于传统和深度baseline                |

| **Exp 7: 源分离可解释性**  | S2+S3 混合                    | 源-伪迹对应准确率                  | ICA 成分标定                                   | Φ_spatial 的非线性成分是否比 ICA 的线性成分更"纯净"         |

### 3.2 关键实验的预期发现

**Exp 6（跨被试泛化）是最重要的实验**：

```
假设结果:
  原始数据 + DANN:   跨被试 F1 87.6% → 58.6%  (-29.0%)
  ICA净化 + DANN:    跨被试 F1 87.6% → 65.2%  (-22.4%)  ← ICA 有一定帮助
  本文净化 + DANN:   跨被试 F1 87.6% → 75.1%  (-12.5%)  ← 本文方法

解释:
  - ICA 消除了一部分线性可分的伪迹（眼动、肌电），
    但不能处理非线性的容积传导混合
  - 本文的源分离 + 任务感知保真：
    (a) 非线性分离 → 更干净的信号
    (b) 保留了 P300/ERD 的任务特征 → 下游分类器有更好的信号基础
    (c) 结论：数据质量差异解释了 ~16.5% 的跨被试降幅
```

## 4. Discussion 部分的关键论点

### 4.1 数据质量是 DG 的隐藏瓶颈

```
论点: 现有的 DG 研究将精力集中在"如何对齐特征分布"，
      却忽视了"对齐的特征本身是否干净"。
      
      DANN/MMD/CORAL 在做什么？
      → 在脏数据上学"域不变特征"
      → 可能学到的是"跨被试都有的颞肌EMG模式"而不是"跨被试都有的神经响应"

      本文证明:
      净化后的数据 + 简单的 DG 方法 > 脏数据 + 复杂的 DG 方法
```

### 4.2 从"数据收集"到"数据工程"的范式转移

```
传统思维: EEG数据采集 = 戴上帽子 + 跑范式
本文立场: EEG数据采集 = 精密设计的4-Session实验工程
          - Session 2 (纯伪迹) 和 Session 3 (纯任务) 的物理分离
          - 这种设计使"Ground Truth"从相对概念变成绝对概念

含义: 如果社区接受这种范式，以后"没有配对的干净/噪声数据"
      的降噪论文将不再被认为是可靠的。
```

### 4.3 这篇论文在研究议程中的位置

```
Paper 1 (本文): 数据净化基础设施
  产出: 净化后的 EEG 数据集 + 冻结的 Φ_spatial
  ↓
Paper 2 (后续): Foundation Model 预训练
  输入: 净化后数据 → Mamba2 自监督预训练
  核心问题: 在干净数据上预训练的 Foundation Model，
           是否比在脏数据上预训练的模型有更好的跨任务泛化？
  ↓
Paper 3 (后续): 在线自适应 BCI 系统
  输入: 冻结的 Φ_spatial + Φ_base + 快慢双系统
  核心问题: 在线源分离 + 在线任务自适应是否能在
           真实世界 NeuroBuds 场景中维持长期稳定性能？
```

### 4.4 局限性（诚实披露）

1. 4-Session 协议的总采集时间 ~56 分钟/被试，对临床场景可行，对大规模 consumer 部署不现实。未来需要研究"最少需要多少Session的数据才能训出可用的 Φ_spatial"
2. Session 2 的伪迹是"独立执行的"，但真实场景中伪迹和任务信号是**同时发生**的（如：看到靶刺激的同时眨了眼）。线性叠加假设可能不完美
3. 本文在临床帽（32-64通道）上验证；向耳周 EEG（8通道）的迁移需要额外验证
4. Φ_spatial 的源数量 K 是超参数——目前没有理论指导如何选择最优 K
